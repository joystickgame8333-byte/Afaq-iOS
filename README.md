# أفق — آيفون

واجهة عربية بخط المسيري وزجاج حول وقت الصلاة، وخلفيات تتدرج من الفجر إلى الليل. مبني بـ SwiftUI، الحد الأدنى iOS 18 مع Liquid Glass على iOS 26+.

## المواقيت

يستخدم نفس تقويم صلاتي السنوي دون تعديل، مع فروق المدن والتوقيت الصيفي Asia/Jerusalem. صلاة قادمة وعد تنازلي مباشر، وتبديل جدول الغد بعد العشاء. اختيار المدينة يدويًا أو أقرب مدينة بالموقع من الإعدادات، والافتراضي تل السبع. المواقيت تعمل دون اتصال مع تحديث التقويم من مصدر صلاتي عند توفر الشبكة.

تفاصيل الدراسة والنقل والتحقق في [PRAYER-INTEGRATION.md](PRAYER-INTEGRATION.md). معاينة المظهر في الإعدادات تستخدم أوقاتًا توضيحية فقط. الخلفية بصرية تقريبية حسب ساعة الجهاز. التنبيهات والأذان والقبلة لم تُفعّل.

## البناء والتجربة

على Mac مع Xcode 26+: شغّل `bash tools/prepare-assets.sh` وافتح `Afaq.xcodeproj` واختر scheme باسم Afaq. في GitHub Actions تُنفّذ اختبارات محرك المواقيت ثم يُبنى ملف iPhone غير موقّع وينشر في Releases. يحتاج IPA طريقة التثبيت والتوقيع المعتادة، ولا يُثبّت بفتحه في Safari.

التحقق البصري وصلاحية الموقع على آيفون المستخدم؛ لا ندّعي تجربة جهاز فعلي من بيئة Windows.
